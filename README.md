# Bazaart Growth Audit

**Live → https://eddieatadapty.github.io/bazaart-flow-rebuild/**

Five ideas to turn more Bazaart users into subscribers, each built into a clickable version of Bazaart's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Keep the ad’s promise, then ask what they sell | +10–20% CR to purchase |
| 02 | Their first product shot, before the paywall | +10–20% CR to purchase |
| 03 | Proof, a clear trial and the year as a monthly price | +10–15% CR · ARPU +10–15% |
| 04 | Catch the people who close the paywall | +10–15% ARPU |
| 05 | Ask for the account after the paywall | +5–10% CR · ARPU +10–17% |

Every price, rating and feature comes from Bazaart's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for Bazaart. They overlap, so they don’t add up. The ads layer carries no range: only a test per ad can give one.

Static single page, no build step: `python3 -m http.server`.
